# Subnet Cheatsheet

Visual reference table for all IPv4 subnet prefixes /0 to /32. Click any row to see expanded details. Everything runs client-side.

**[Live Demo](https://gmowses.github.io/subnet-cheatsheet)**

## Features

- Complete table for /0 to /32
- Shows: prefix, subnet mask, wildcard, usable hosts, common use
- Searchable by prefix, mask, host count, or use description
- Expandable rows with: binary mask, subnet bits, host bits, example CIDR
- Color-coded by prefix range
- Dark/light mode
- i18n: English and Portuguese (BR)
- Client-side only

## Tech Stack

React 19 + TypeScript, Tailwind CSS v4, Vite, Lucide icons, GitHub Pages
